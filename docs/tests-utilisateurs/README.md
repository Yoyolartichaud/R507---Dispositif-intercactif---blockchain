# Tests utilisateurs

Le sujet demande au moins 2 tests avec des personnes extérieures au groupe, qui
n'ont pas suivi le cours R507 et qui ne reçoivent aucune explication orale avant
de commencer. Chaque test a sa fiche dans ce dossier ; les problèmes relevés
donnent lieu à des issues.

## Déroulé proposé pour les prochains tests

1. Ne rien expliquer avant : la personne découvre l'expérience seule.
2. Lui demander de dire à voix haute ce qu'elle comprend et ce qui la bloque.
3. Ne pas l'aider pendant le parcours ; noter où elle hésite ou se trompe.
4. À la fin, lui demander d'expliquer avec ses mots : ce qu'est un bloc, une
   empreinte, où est rangée la blockchain, à quoi sert un mineur.
5. Recopier ses remarques telles quelles dans une nouvelle fiche, puis créer une
   issue par problème.
